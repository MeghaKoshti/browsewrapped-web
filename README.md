# BrowseWrapped Web

BrowseWrapped transforms browser history into an interactive visualization of your learning journey, interests, and online habits.

Inspired by Spotify Wrapped, BrowseWrapped helps users discover:

* Knowledge maps
* Learning timelines
* Interest trends
* Search evolution
* Topic exploration
* Skill development patterns

## Features

### Interactive Analytics

* Topic distribution charts
* Interest growth tracking
* Learning journey timeline
* Domain analytics
* Search behavior insights

### Visualizations

* Knowledge graphs
* Topic relationship networks
* Time-based activity charts
* Trend analysis dashboards

### Privacy First

* Browser history is processed securely
* Users control uploaded data
* No unnecessary tracking

## Tech Stack

* React
* Vite
* Tailwind CSS v4
* Recharts
* React Flow
* Axios
* React Router

## Development

### Prerequisites

* Node.js
* npm

If using mise:

```bash
mise install
mise trust
```

### Setup

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```
